本表区分能力记录与当前证据。2026-07-14 的局部可靠性验证继续保留，但不能支撑“全部功能已闭环”。本次已确认的缺口如下；未逐项走完的新鲜用户流程标为待复核，不推断其全部失效或全部正常。

状态定义：

- **已发现缺口**：已有本地复现或代码路径证据，待实现修复和验收。
- **历史记录待复核**：保留旧能力说明，未按本轮完整交互与结果口径重新验证。
- **本地验证通过**：指定版本、指定场景在隔离环境通过；须附证据，不能代替 Telegram 验收。
- **Telegram 验收通过**：指定版本与目标群/用户/对象完成真实操作及结果回读；只覆盖记录范围。
- **策略关闭**：产品明确关闭的能力，不计为实现失败。

2026-10-15追加：通用版本CI1272项通过，0017与136个源文件哈希线上匹配；四快捷入口、三类空列表、广告中文检索/筛选及空恢复页已在私聊检查。夜间管控父页新增入口已见；通知投递、持久切换、等级标签及提醒收件、复制/联盟真实副作用没有现场验证。完整边界和客户端显示延迟见上述生产记录；38项自有功能未全量重跑。

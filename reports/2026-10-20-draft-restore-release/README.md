# 日历草稿恢复修复与生产发布记录

## 修复内容

恢复定时消息、轮播规则及轮播消息草稿时清除临时日历状态，保留目标群、对象、输入字段和业务值。已过期的日历按钮不能重新写入；恢复后直接接受手动时间输入。

端到端回归揭示定时/轮播输入另开数据库会话，与上层草稿版本校验持有的锁自等待。相关适配器现传递并复用原事务，保存与版本校验保持同一事务；独立调用仍可自行创建会话。没有取消版本校验或提前释放保护锁。
